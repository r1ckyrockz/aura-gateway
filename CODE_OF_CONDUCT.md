# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions focused on the work. Harassment or discrimination of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer through the contact details on the [maintainer's GitHub profile](https://github.com/r1ckyrockz). All reports are handled confidentially.
